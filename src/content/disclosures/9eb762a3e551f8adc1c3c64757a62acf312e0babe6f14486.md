## What this page is

A test entry reachable only at its full path. It carries `unlisted: true`, so the
build excludes it from:

- the disclosure index at `/`
- the RSS feed at `/rss.xml`
- the sitemap at `/sitemap-0.xml`

and serves it with `<meta name="robots" content="noindex, nofollow, noarchive">`.

The slug is 24 random bytes from a CSPRNG, hex-encoded — 192 bits of entropy, which
is not guessable by brute force.

## What this does not protect against

The path is obscured, not protected. It still leaks if:

1. **The source repo is public** — the filename is the URL, so anyone reading
   `src/content/disclosures/` has the path. This is the big one.
2. **You link outward from this page** — the destination sees the full path in the
   `Referer` header. Add `rel="noreferrer"` to outbound links here.
3. **Someone you shared it with** forwards it, pastes it into a scanner, or opens it
   in a browser that syncs history or prefetches URLs.
4. **It gets archived** — archive.org and similar honor `noindex` inconsistently.

A URL that returns 200 is public. Treat this as "not advertised", never as access
control. For anything embargoed, do not deploy it: use `draft: true`, which keeps
the entry out of `dist/` entirely.

    if (_status == _ENTERED) revert ReentrancyGuardReentrantCall();
